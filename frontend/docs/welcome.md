# Welcome to Help

This is a short, plain-language guide to every section of Surfing the Frequencies (LMBoK) — what each one does, why it exists, and how it fits together.

These docs are markdown files, loaded on demand, so they cost almost nothing on a slow connection — you're only downloading the page you actually open.

**Start with [Prosopon](prosopon)** if you're wondering how the platform gets to know you, or **[The 15 Arts](15-arts)** if you're wondering what the whole thing is organized around.

If something here is out of date or confusing, that's worth flagging — these docs live in the same open-source repo as the platform itself.
