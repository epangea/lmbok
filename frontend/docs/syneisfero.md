# Syneisfero — contribute a LECKO

Almost everything you learn on this platform is generated fresh by AI. But every so often, something belongs in the system as a fixed, human-written piece — a **LECKO** — because it needs a human's judgment, not a generated approximation.

Syneisfero (Greek, roughly "to contribute together") is where community members can submit one. It's intentionally the exception, not the default — most learning content never needs to pass through here.
